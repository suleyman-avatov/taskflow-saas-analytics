# Executive Summary: TaskFlow SaaS Analytics (Jan–Jun 2024)

## 🎯 Ключевой вывод для CFO
Рост MRR замедлился с **53% до 13%** не из-за падения продаж, а из-за четырёхкратного роста оттока в апреле 2024 г. Канал `paid_ads` является токсичным активом (**LTV/CAC = 0.01**), генерирующим 100% churn к M2. Даже «здоровые» каналы (`organic`, `referral`) не достигают порога безубыточности (max LTV/CAC = 0.92), что требует пересмотра ценообразования или расширения горизонта окупаемости.

## 🔍 Результаты SQL-анализа по этапам

### 1. Динамика MRR и темп роста
-   Абсолютный MRR вырос на **217%** ($3.7K → $11.8K).
-   Темп роста упал с **53.5%** (февраль) до **13.7%** (июнь).
-   Точка перелома тренда: **апрель 2024** (рост降至 10.9%).

### 2. Декомпозиция MRR (New vs Churned)
-   В июне показан лучший приток за полгода ($4,097), но чистый прирост меньше февральского ($1,418 vs $1,986).
-   Отток в апреле съел **72%** нового притока (-$2,244 при притоке $3,114).
-   Вывод: проблема не в маркетинге, а в удержании («дырявое ведро»).

### 3. Retention по когортам каналов
-   `organic`: 96.7% → 93.3% (эталонное удержание).
-   `referral`: 90.2% → 90.5% (стабильное качество).
-   `paid_ads`: **0.0%** во всех когортах (полная неактивность после 30 дней).
-   Гипотеза подтверждена: paid_ads трафик токсичен.

## ✅ Рекомендации для CFO

### Тактические (немедленно)
1.  **Остановить все кампании paid_ads.** Экономия ~$5K/мес при нулевой потере качественного притока.
2.  **Перераспределить бюджет на referral-программу.** Единственный канал с ratio > 0.4.
3.  **Аудит онбординга для April-когорты.** Выявить причину всплеска оттока в апреле.

### Стратегические (Q3 2024)
1.  **Пересмотр ценообразования.** Pro-тариф $99 слишком низок для B2B; рассмотреть повышение до $149 или введение annual billing.
2.  **Расширить горизонт LTV.** Перейти с 6-месячного на 12-месячный расчёт для корректной оценки organic/referral.
3.  **Внедрить алертинг.** Автоматическое уведомление при падении growth_rate_pct < 15% два месяца подряд.

## 🗂️ Структура витрины данных для дашборда

Для построения интерактивного дашборда рекомендуется создать сводную таблицу `dashboard_vw` на основе результатов 4 SQL-анализов:

```sql
CREATE VIEW dashboard_vw AS
-- Объединяет результаты всех 4 анализов в единую плоскую структуру
-- Позволяет строить графики без сложных JOIN в BI-инструменте
SELECT 
    d.month,
    d.mrr,
    d.growth_rate_pct,
    dc.new_mrr,
    dc.churned_mrr,
    dc.net_change,
    r.channel,
    r.cohort,
    r.retention_m2_pct,
    u.period,
    u.avg_ltv,
    u.cac,
    u.ltv_cac_ratio,
    u.status
FROM mrr_dynamics d
JOIN mrr_decomposition dc ON d.month = dc.month
CROSS JOIN retention_cohorts r
CROSS JOIN unit_economics u
WHERE d.month BETWEEN '2024-01' AND '2024-06';
